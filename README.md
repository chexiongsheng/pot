# pot

面向 AI 的 Unity 游戏开发框架，基于 Puerts。

名字取自普洱（Puerts 名字的来源）的茶壶：Runner 是壶，游戏包是茶。用 JS/TS 代码和 JSON 配置写成的游戏包，在 Runner 里加载、热重载、预览。AI 通过 MCP/CLI 读取日志和截图、操作游戏，形成开发闭环；人可以在电脑或手机上实时试玩、提意见。发布时用 Unity 正常打包成独立 App。
